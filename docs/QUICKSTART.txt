繁體中文
--------
自訂預設存於使用者資料庫，套用只更新目前圖樣，不會開啟另一份專案。舊預設套用第一個圖樣圖層，原記錄仍保留。新建、開啟另一份專案或關閉時，未儲存變更可選擇儲存、不儲存或取消。
可從資料夾拖入 PNG、JPG、WebP 或 SVG 成為圖片圖層；右側顯示原始尺寸。點擊畫布左上角的尺寸可編輯寬高，比例鎖定也會存入 .ctm。

解壓縮 ZIP 後，開啟 C-TextureMaker.exe。請保留同一資料夾內的 app 與 DLL，並將整個資料夾放在可寫入的位置。
升級時先關閉舊版，再將舊版的 data 資料夾複製到新版程式旁，可延續自動存檔、偏好、自訂預設與形狀庫；也可直接開啟先前另存的 .ctm。
需要 Windows x64、.NET Framework 4.7.2 或更新版本，以及系統已安裝的 Microsoft Edge WebView2 Runtime。成品離線執行，不需伺服器、帳號或 Node.js。
左側選圖樣、右側調整參數；滾輪縮放，空白鍵＋拖曳移動畫布。無縫模式配合畫布週期排列；以 3 × 3 預覽檢查接縫，匯出仍是單格。
PNG 可輸出透明或實色背景，最長邊上限 8192 px、總像素上限 32 MP。程序式圖形匯出為向量 SVG；匯入的 PNG 會以點陣圖嵌入 SVG。
下方工具列可選一般游標或手形工具；格點／多邊形的繪製與擦除可調筆刷直徑，一筆一次復原。形狀選單旁的共用形狀庫支援 PNG／SVG（每個最多 4 MiB，合計 40 個／32 MiB），可跨半色調、格點、多邊形與符號使用。工程格線分組設定主格線、對角線虛線與留白。
形狀庫中的鉛筆按鈕可重新命名；套用形狀後，在「外觀」開啟「依主色染色」。兩點連線依序點選端點，重選相同一對可刪除，Esc 取消起點。
左下「圖層」的圖片按鈕可新增圖片遮罩：PNG/JPG/WebP（16 MiB）或 SVG（4 MiB）。直接調整圖層閾值、反轉；選取圖片可獨立移動、縮放、旋轉與翻轉。所有圖樣改變密度仍受同一遮罩影響，單元編輯會保留。單格中拖曳邊框移動、角點縮放、圓點旋轉。來源隨專案保存並嵌入 SVG 遮罩；圖片接縫請用 3 × 3 檢查。
每個圖層會分別記住各種圖樣的參數、外觀與單元編輯；切換圖樣不會重設，專案存檔也會保留。恢復預設只影響目前圖樣。
Low Poly 可由配色漸層或照片逐面上色；圖片圖層可切換黑白遮罩／圖片色彩，為所有圖樣上色。等高線可開啟立體填色，調整內外陰影、範圍、距離、方向、顏色與不透明度。這些圖樣設定需要 1.4.0 或更新版本。
Ctrl+S 首次選擇 .ctm 位置，之後直接更新原檔；旁邊箭頭或 Ctrl+Shift+S 另存新檔。Ctrl+O 開啟，Ctrl+E 匯出；Ctrl+Z 復原，Ctrl+Shift+Z 或 Ctrl+Y 重做。
工作與偏好保存在程式旁的 data 資料夾。關閉前確認狀態列顯示「已自動儲存」；搬移或備份設計時另存 .ctm 專案。
本專案自有程式碼採 MPL-2.0；Transitions.dev 與 Microsoft WebView2 元件依各自授權條款使用。詳見 LICENSE、LICENSE-SCOPE.md、THIRD-PARTY-NOTICES.txt 與程式包內的 LICENSE-WebView2.txt。

ENGLISH
-------
User presets update the current pattern without opening another project. Legacy presets apply their first pattern layer and keep the original record. New, Open and Close offer Save, Don’t save or Cancel when there are unsaved changes.
Drop PNG, JPG, WebP or SVG files into the app to add image layers; original dimensions appear in the inspector. Click the canvas dimensions to edit them. Aspect ratio locking is saved in .ctm projects.

Extract the ZIP and open C-TextureMaker.exe. Keep the app folder and DLL files beside the executable, and place the whole folder somewhere writable.
To upgrade, close the older version, then copy its data folder beside the new app to keep autosave, preferences, user presets and the shape library. Previously saved .ctm files can also be opened directly.
Requirements: Windows x64, .NET Framework 4.7.2 or later, and the Microsoft Edge WebView2 Runtime installed on the system. The app runs offline; no server, account, or Node.js is needed.
Choose a pattern on the left and adjust it on the right. Use the mouse wheel to zoom and Space+drag to pan. Seamless mode fits the pattern to the canvas period; use the 3 × 3 preview to inspect seams. Exports contain one tile.
PNG supports transparent or solid backgrounds, up to an 8192 px longest edge and 32 MP total. Procedural shapes export as vector SVG; imported PNGs remain embedded raster images.
Use the bottom toolbar to switch between cursor and hand tools. Dot/polygon paint and erase brushes have adjustable diameters and one undo per stroke. The shared shape library next to the shape menu accepts PNG/SVG (4 MiB per file, 40 shapes / 32 MiB total) across halftone, dots, polygons and symbols. Technical grid controls group base lines, independent diagonal dashes and gaps.
Use the pencil button in the shape library to rename a shape. After applying it, turn on Tint with primary color under Appearance. Click two cells to connect them; connect the same pair again to remove it, or press Esc to cancel the start.
Use the image button beside Layers to add an image mask: PNG/JPG/WebP (16 MiB) or SVG (4 MiB). Adjust the threshold/invert in the layer list; select the image to move, scale, rotate or flip it independently. The mask affects all patterns at any density while preserving cell edits. In tile view, drag the frame, corners or top circle to move, resize or rotate. Sources are saved in projects and embedded as SVG masks. Inspect image seams in 3 × 3 view.
Each layer remembers the parameters, appearance and cell edits for every pattern you use. Switching patterns and saving projects preserve those settings; Reset affects only the current pattern.
Low Poly uses palette gradients or sampled photo colors. Image layers can switch between masks and image colors for every pattern. Contours offer depth shading with inner/outer shadow controls. These pattern settings require 1.4.0 or later.
Ctrl+S chooses a .ctm destination once, then updates that file. The adjacent arrow or Ctrl+Shift+S opens Save As. Ctrl+O opens one, and Ctrl+E exports. Ctrl+Z undoes; Ctrl+Shift+Z or Ctrl+Y redoes.
Work and preferences are saved in the data folder beside the app. Before closing, check that the status bar says “Autosaved.” Save a .ctm project separately when moving or backing up a design.

Pixel
左側選 Pixel，匯入圖片作為色彩圖層，再選回 Pixel 調整。像素量拉桿控制長邊 4–512 格，短邊依畫布比例計算。色數上限為 2–256；可自動取色、選灰階或復古綠色板，點擊色塊改為自訂色。圖片可在自己的圖層調整尺寸、旋轉及翻轉。
「目前畫布尺寸」保留大圖尺寸；「實際像素格尺寸」將每格輸出為 1 px，例如 64 × 32。此設定同時作用於 SVG 與 PNG，且不縮小專案畫布。PNG 先以格數合成可見圖層，再用最近鄰方式放大；色數限制只適用 Pixel 圖層，背景與其他圖層可能增加成品色數。Pixel 使用二值透明度讓輪廓清晰。

Pixel
Select Pixel, import an image as a color layer, then select Pixel again. The pixel-count slider sets 4–512 cells on the long edge; the short edge follows the canvas ratio. Limit colors to 2–256, choose automatic, grayscale or retro green, and edit swatches to create a custom palette. Transform the source on its own image layer.
Canvas size keeps the large output; Actual pixel grid exports each cell as 1 px (for example 64 × 32), for both SVG and PNG, without resizing the project canvas. PNG composites visible layers at grid resolution before nearest-neighbor enlargement. The color limit applies to the Pixel layer; backgrounds and other layers may add colors. Pixel transparency is binary for crisp edges.

Pixel
Pixel を選び、色レイヤーとして画像を読み込んでから Pixel を再選択します。スライダーで長辺を 4–512 セルに調整し、短辺はキャンバスの比率に合わせます。色数は 2–256 色。画像から抽出・グレースケール・レトログリーンを選べ、色をクリックするとカスタムパレットになります。元画像の変形は画像レイヤーで調整します。
キャンバスサイズは大きな出力を維持し、実ピクセルサイズは各セルを 1 px（例：64 × 32）で SVG・PNG に出力します。プロジェクトのキャンバスは変更しません。PNG はグリッド解像度で表示レイヤーを合成してから最近傍法で拡大します。色数の上限は Pixel レイヤーのみで、背景や他のレイヤーにより出力色数が増える場合があります。透明度は二値で輪郭を鮮明に保ちます。

圖片來源與 Pixel / Image sources and Pixel / 画像ソースと Pixel
-------------------------------------------------------------
各圖樣的「圖片來源」切換為「全圖層／圖片／無圖片」。「圖片」使用下方最近的圖片或群組，連續多個效果可共用同一基底，箭頭表示套用關係；不透明上層仍會遮住下層。舊專案原有指定來源先保留，重新按「圖片」後才改依圖層位置取用。
Ctrl＋點擊可複選，Shift＋點擊選取範圍；Ctrl+G 群組，Ctrl+Shift+G 解除群組。拖曳圖層可上下排序，拖到群組中央可移入，拖到列表的最外層區域可移出。群組可展開／收合、改名及隱藏，隱藏群組會一併隱藏內容。圖片模式為「黑白遮罩／圖片色彩」；彩色圖片在尚無處理結果時顯示原圖，效果產生後顯示處理結果。群組專案請使用 1.5.0 或更新版本開啟。
Pixel 可依長邊格數、寬度或像素塊尺寸調整密度，並選平均／最近鄰取樣、2–256 色、抖色及亮度／對比／飽和度。「實際像素格尺寸」將每格輸出為1 px；PNG會合成所有可見圖層。與其他工具比較時，請先對齊實際輸出寬高及色數。

Image source now switches between All layers, Image and No image. Image uses the nearest image or group below; consecutive effects share that base, indicated by clipping arrows. Opaque upper layers cover lower ones. Existing source bindings in old projects remain until you select Image again.
Ctrl-click selects multiple layers; Shift-click selects a range. Ctrl+G groups and Ctrl+Shift+G ungroups. Drag to reorder, drop in a folder's center to move inside, or on the root drop area to move out. Groups support collapse, rename and visibility, including their contents. Image modes are Black / white mask and Image colors; color images show the original until an effect produces output. Open grouped projects with 1.5.0 or later.
Pixel density can follow long-edge count, width, or block size. Choose average/nearest sampling, 2–256 colors, dithering, and brightness/contrast/saturation. Actual pixel grid exports one cell as 1 px; PNG composites all visible layers. Match output width, height and color count when comparing tools.

画像ソースは「全レイヤー／画像／画像なし」を切り替えます。「画像」は直下にある画像またはグループを参照し、連続する複数の効果で同じベースを共有します。矢印が参照関係を示します。上の不透明部分は下を覆います。旧プロジェクトの参照は「画像」を選び直すまで保持します。
Ctrl＋クリックで複数選択、Shift＋クリックで範囲選択。Ctrl+Gでグループ化、Ctrl+Shift+Gで解除します。ドラッグで並べ替え、フォルダー中央にドロップして移入、ルートのドロップ領域に移動して外へ出せます。グループは折りたたみ、名前変更、内容ごとの表示切り替えに対応します。画像モードは「白黒マスク／画像の色」です。効果が生成されるまでは元画像を表示し、生成後は処理結果を表示します。グループを含むプロジェクトは1.5.0以降で開いてください。
Pixelの密度は長辺のセル数、幅、ブロックサイズで調整できます。平均／最近傍サンプリング、2〜256色、ディザリング、明るさ／コントラスト／彩度を設定できます。「実ピクセルサイズ」は1セルを1 pxで出力し、PNGは表示中の全レイヤーを合成します。他のツールと比べる際は出力の幅・高さ・色数を揃えてください。

形狀重繪 / Shape redraw / 形状再描画
----------------------------------
選擇「形狀重繪」並匯入圖片，按「生成」建立可編輯色塊。分塊細碎程度越高會保留更多小區域，調整後按「重新分割」套用；有手動編輯時會先詢問。直邊程度越高，輪廓折線越簡潔，調整不會清除單元編輯。可切換色塊／三色／輪廓線，並調整線稿與色板；原色是區域代表色，不保留原圖紋理。Ctrl＋點擊可複選區塊，點擊空白取消選取；隱藏工具單擊切換顯示，填充顏色可用於改色。藍色邊緣提示滑鼠下的區塊。螢幕取色以左鍵確認，右鍵或 Esc 取消。復原／重做最多保留30步。結果與編輯隨專案保存；生成形狀會跟隨來源圖片移動、縮放、旋轉與翻轉，替換圖片或改變多張來源的相對配置後請重新生成。複雜背景會一起轉換，透明 PNG 最適合剪影效果。
Select Shape redraw, import an image and Generate editable regions. Higher Region detail retains smaller pieces; use Re-segment after changing it, with confirmation when manual edits exist. Higher Edge straightness simplifies boundaries without clearing region edits. Switch between color blocks, three colors and outlines, with line art and palette controls. Original colors are representative region colors, not original textures. Ctrl-click to multi-select; click empty space to deselect. The hide tool toggles a region on each click; use Fill color to recolor it. Blue hover edges identify the region under the pointer. Screen color picking confirms with left-click and cancels with right-click or Esc. Undo/redo retains up to 30 steps. Results and edits are saved in projects, and generated shapes follow source movement, scale, rotation and flips. Regenerate after replacing sources or changing their relative arrangement. Backgrounds are also converted; transparent PNG works best for cutouts.
「形状再描画」で画像を読み込み、生成して編集可能な領域を作ります。「分割の細かさ」を上げると小さな領域が残り、変更後は再分割で反映します。手動編集がある場合は確認します。「直線化」は輪郭を簡略化し、領域の編集を保持します。色面／3色／輪郭線を切り替え、線画とパレットも調整できます。元の色は領域の代表色で、元画像のテクスチャではありません。Ctrl＋クリックで複数選択、空白をクリックして解除します。非表示ツールはクリックごとに表示を切り替え、「塗りつぶしの色」で色変更できます。青い枠はポインター下の領域を示します。画面の色取得は左クリックで確定、右クリックかEscでキャンセルします。元に戻す／やり直しは最大30段階です。結果と編集はプロジェクトに保存され、形状は元画像の移動・拡大縮小・回転・反転に追従します。画像の置き換えや複数画像の相対配置を変更した場合は再生成してください。背景も変換されるため、切り抜きには透明PNGが適しています。
