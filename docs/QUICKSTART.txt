繁體中文
--------
解壓縮 ZIP 後，開啟 C-TextureMaker.exe。請保留同一資料夾內的 app 與 DLL，並將整個資料夾放在可寫入的位置。
升級時先關閉舊版，再將舊版的 data 資料夾複製到新版程式旁，可延續自動存檔、偏好與形狀庫；也可直接開啟先前另存的 .ctm。
需要 Windows x64、.NET Framework 4.7.2 或更新版本，以及系統已安裝的 Microsoft Edge WebView2 Runtime。成品離線執行，不需伺服器、帳號或 Node.js。
左側選圖樣、右側調整參數；滾輪縮放，空白鍵＋拖曳移動畫布。無縫模式配合畫布週期排列；以 3 × 3 預覽檢查接縫，匯出仍是單格。
PNG 可輸出透明或實色背景，最長邊上限 8192 px、總像素上限 32 MP。程序式圖形匯出為向量 SVG；匯入的 PNG 會以點陣圖嵌入 SVG。
下方工具列可選一般游標或手形工具；格點／多邊形的繪製與擦除可調筆刷直徑，一筆一次復原。形狀選單旁的共用形狀庫支援 PNG／SVG（每個最多 4 MiB，合計 40 個／32 MiB），可跨半色調、格點、多邊形與符號使用。工程格線分組設定主格線、對角線虛線與留白。
形狀庫中的鉛筆按鈕可重新命名；套用形狀後，在「外觀」開啟「依主色染色」。兩點連線依序點選端點，重選相同一對可刪除，Esc 取消起點。
左下「圖層」的圖片按鈕可新增圖片遮罩：PNG/JPG/WebP（16 MiB）或 SVG（4 MiB）。直接調整圖層閾值、反轉；選取圖片可獨立移動、縮放、旋轉與翻轉。所有圖樣改變密度仍受同一遮罩影響，單元編輯會保留。單格中拖曳邊框移動、角點縮放、圓點旋轉。來源隨專案保存並嵌入 SVG 遮罩；圖片接縫請用 3 × 3 檢查。含遮罩的專案需要 1.3.0 或更新版本。
Ctrl+S 儲存 .ctm 專案，Ctrl+O 開啟，Ctrl+E 匯出；Ctrl+Z 復原，Ctrl+Shift+Z 或 Ctrl+Y 重做。
工作與偏好保存在程式旁的 data 資料夾。關閉前確認狀態列顯示「已自動儲存」；搬移或備份設計時另存 .ctm 專案。

ENGLISH
-------
Extract the ZIP and open C-TextureMaker.exe. Keep the app folder and DLL files beside the executable, and place the whole folder somewhere writable.
To upgrade, close the older version, then copy its data folder beside the new app to keep autosave, preferences and the shape library. Previously saved .ctm files can also be opened directly.
Requirements: Windows x64, .NET Framework 4.7.2 or later, and the Microsoft Edge WebView2 Runtime installed on the system. The app runs offline; no server, account, or Node.js is needed.
Choose a pattern on the left and adjust it on the right. Use the mouse wheel to zoom and Space+drag to pan. Seamless mode fits the pattern to the canvas period; use the 3 × 3 preview to inspect seams. Exports contain one tile.
PNG supports transparent or solid backgrounds, up to an 8192 px longest edge and 32 MP total. Procedural shapes export as vector SVG; imported PNGs remain embedded raster images.
Use the bottom toolbar to switch between cursor and hand tools. Dot/polygon paint and erase brushes have adjustable diameters and one undo per stroke. The shared shape library next to the shape menu accepts PNG/SVG (4 MiB per file, 40 shapes / 32 MiB total) across halftone, dots, polygons and symbols. Technical grid controls group base lines, independent diagonal dashes and gaps.
Use the pencil button in the shape library to rename a shape. After applying it, turn on Tint with primary color under Appearance. Click two cells to connect them; connect the same pair again to remove it, or press Esc to cancel the start.
Use the image button beside Layers to add an image mask: PNG/JPG/WebP (16 MiB) or SVG (4 MiB). Adjust the threshold/invert in the layer list; select the image to move, scale, rotate or flip it independently. The mask affects all patterns at any density while preserving cell edits. In tile view, drag the frame, corners or top circle to move, resize or rotate. Sources are saved in projects and embedded as SVG masks. Inspect image seams in 3 × 3 view. Mask projects require 1.3.0 or later.
Ctrl+S saves a .ctm project, Ctrl+O opens one, and Ctrl+E exports. Ctrl+Z undoes; Ctrl+Shift+Z or Ctrl+Y redoes.
Work and preferences are saved in the data folder beside the app. Before closing, check that the status bar says “Autosaved.” Save a .ctm project separately when moving or backing up a design.

日本語
-------
ZIP を展開して C-TextureMaker.exe を起動します。app フォルダーと DLL は実行ファイルの隣に残し、書き込み可能な場所に全体を置いてください。
アップグレード時は旧版を終了し、data フォルダーを新版アプリの隣にコピーすると、自動保存・設定・形状ライブラリを引き継げます。保存済みの .ctm も直接開けます。
必要環境は Windows x64、.NET Framework 4.7.2 以降、システムにインストール済みの Microsoft Edge WebView2 Runtime です。オフラインで動作し、サーバー、アカウント、Node.js は不要です。
左側でパターンを選び、右側で調整します。マウスホイールで拡大縮小、Space キーを押しながらドラッグするとキャンバスを移動できます。シームレスモードはキャンバス周期に合わせます。3 × 3 プレビューで継ぎ目を確認でき、書き出しは 1 タイルです。
PNG は透明または単色背景に対応し、長辺 8192 px、総画素数 32 MP が上限です。プロシージャル図形はベクター SVG になり、読み込んだ PNG はラスター画像として SVG に埋め込まれます。
下のツールバーでカーソル・手のひらを切り替えます。ドット／多角形の描画・消去はブラシ直径を調整でき、1ストロークずつ元に戻せます。形状メニュー横の共通ライブラリはPNG／SVG（1個4 MiB、40個・合計32 MiB）をハーフトーン、ドット、多角形、シンボルで使用できます。テクニカルグリッドでは基本線・対角線の破線・余白を分けて設定します。
ライブラリの鉛筆ボタンで形状名を変更できます。形状の適用後、「外観」で「メインカラーで着色」を有効にできます。2つのセルを順にクリックすると接続し、同じ組を再選択すると削除、Escで始点を解除します。
左下「レイヤー」横の画像ボタンでマスクを追加：PNG/JPG/WebP（16 MiB）またはSVG（4 MiB）。レイヤー欄でしきい値・反転を調整し、画像を選ぶと独立して移動・拡大縮小・回転・反転できます。密度を変えてもすべてのパターンに同じマスクが適用され、セル編集も保持します。タイル表示で枠・角・上の丸をドラッグして変形できます。元画像はプロジェクトに保存され、SVGマスクにも埋め込まれます。3 × 3で画像の継ぎ目を確認してください。マスクを含むプロジェクトは1.3.0以降で開いてください。
Ctrl+S で .ctm プロジェクトを保存、Ctrl+O で開き、Ctrl+E で書き出します。Ctrl+Z で元に戻し、Ctrl+Shift+Z または Ctrl+Y でやり直します。
作業と設定はアプリの隣の data フォルダーに保存されます。終了前にステータスバーの「自動保存済み」を確認し、デザインの移動やバックアップには .ctm プロジェクトを別途保存してください。
本プロジェクト独自のコードは MPL-2.0 です。Transitions.dev と Microsoft WebView2 には各自の条件が適用されます。LICENSE、LICENSE-SCOPE.md、THIRD-PARTY-NOTICES.txt、ポータブル版の LICENSE-WebView2.txt を参照してください。
