# C-TextureMaker 1.4.0

[繁體中文](#繁體中文) · [English](#english) · [日本語](#日本語)

## 繁體中文

- 新增 **Low Poly**：調整三角面的密度與形狀，使用配色漸層或匯入照片逐面上色。
- 圖片圖層可切換 **黑白遮罩／圖片色彩**；所有圖樣都能使用圖片上色，隨密度、旋轉與圖片變形即時更新。
- 等高線新增 **立體填色與內外陰影**，可調範圍、距離、方向、顏色與不透明度。
- **儲存會直接更新目前檔案**；按鈕旁下拉選單或 Ctrl+Shift+S 可另存新檔。
- 操作說明加入工具作者與 GitHub 連結；延續最大化邊界修正與各圖樣設定保存。

## English

- Added **Low Poly** with adjustable triangle density and shape variation, palette gradients and flat colors sampled from photos.
- Image layers now switch between **Black / white mask and Image colors**. All patterns can use image colors, updating with density, rotation and image transforms.
- Contours gain **depth shading and inner / outer shadows**, with softness, distance, direction, color and opacity controls.
- **Save updates the current file**. Use its dropdown or Ctrl+Shift+S for Save As.
- The guide now credits the tool author and links to GitHub. Maximized window fixes and per-pattern setting retention are included.

## 日本語

- **ローポリ**を追加。三角面の密度・形状を調整し、配色のグラデーションや写真から採った色を面ごとに適用できます。
- 画像レイヤーで**白黒マスク／画像の色**を切り替え可能。すべてのパターンに着色でき、密度・回転・画像の変形に追従します。
- 等高線に**立体塗り・内側／外側の影**を追加。ぼかし、距離、方向、色、不透明度を調整できます。
- **保存は現在のファイルを更新**。隣のメニューまたはCtrl+Shift+Sで別名保存できます。
- 操作ガイドに作者・GitHubへのリンクを追加。最大化の隙間修正とパターン別の設定保存も含まれます。
