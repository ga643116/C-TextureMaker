# C-TextureMaker 1.7.0

[繁體中文](#繁體中文) · [English](#english) · [日本語](#日本語)

## 繁體中文

- **漫畫網點**：彩圖轉為黑、白、灰分區，可在灰底加入網點，調整大小、密度與形狀，密度上限提高至 2048。
- **線稿提取**：新增透明背景線稿，並同步改善形狀重繪與漫畫網點的線條；可調整細節量、連貫程度、偵測尺度與線寬。
- **貼圖與圖層**：支援 Ctrl+V 或畫布右鍵貼上圖片；點選圖樣庫會新增圖層，保留原有內容。
- **操作改善**：加快圖層切換、顯示切換與圖片貼上處理，更新圖樣縮圖，修正開場動畫前介面閃現。

升級前請關閉舊版，將原本的 data 資料夾複製到新版程式旁，即可保留自動存檔、偏好、預設與形狀庫。含漫畫網點或線稿提取的專案請使用 1.7.0 或更新版本。

## English

- **Manga screen**: convert color images into black, white and gray regions, with optional screentones over gray fill. Adjust size, shape and density up to 2048.
- **Line extraction**: new transparent line art, with improved lines shared by Shape redraw and Manga screen. Adjust detail, continuity, detection scale and line weight.
- **Images and layers**: paste images with Ctrl+V or the canvas context menu. Selecting a pattern adds a layer and preserves existing content.
- **Usability**: faster layer selection, visibility changes and image paste processing; refreshed thumbnails and a fix for the UI flashing before the opening animation.

Before upgrading, close the old version and copy its data folder beside the new app to retain autosaves, preferences, presets and the shape library. Projects with Manga screen or Line extraction require 1.7.0 or later.

## 日本語

- **漫画スクリーン**：カラー画像を黒・白・グレーに変換し、グレーの上に網点を追加できます。サイズ・形状・密度を調整でき、密度の上限は2048です。
- **線画抽出**：透明背景の線画を追加し、形状再描画と漫画スクリーンの線も改善しました。細部・連続性・検出スケール・線幅を調整できます。
- **画像とレイヤー**：Ctrl+Vまたはキャンバスの右クリックメニューで画像を貼り付けられます。パターンを選ぶとレイヤーが追加され、既存の内容を保持します。
- **操作性**：レイヤー選択・表示切り替え・画像貼り付け処理を高速化しました。サムネイルを更新し、起動アニメーション前にUIが一瞬表示される問題を修正しました。

更新前に旧版を終了し、dataフォルダーを新版アプリの隣へコピーすると、自動保存・設定・プリセット・形状ライブラリを引き継げます。漫画スクリーンや線画抽出を含むプロジェクトには1.7.0以降が必要です。
