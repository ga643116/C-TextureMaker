# C-TextureMaker 1.5.0

[繁體中文](#繁體中文) · [English](#english) · [日本語](#日本語)

## 繁體中文

- **自訂預設與專案分離**：套用預設只更新圖樣設定，保留目前專案、畫布與其他圖層。舊預設仍可使用。
- **未儲存提醒**：新建、開啟另一份專案或關閉視窗時，可選擇儲存、不儲存或取消。
- **直接拖入圖片**：從資料夾拖入 PNG、JPG、WebP 或 SVG，立即新增圖片圖層；右側顯示圖片原始尺寸與比例。
- **更方便的畫布尺寸調整**：支援寬高比例鎖定，尺寸預設標示比例，點擊畫布左上角解析度即可編輯。鎖定設定會隨專案保存。

## English

- **Presets are independent of projects**: applying a preset updates pattern settings while keeping the current project, canvas and other layers. Existing presets remain usable.
- **Unsaved changes warning**: choose Save, Don’t save or Cancel before creating a new project, opening another project or closing the window.
- **Drag images into the app**: drop PNG, JPG, WebP or SVG files to add image layers. The inspector shows original dimensions and aspect ratio.
- **Easier canvas sizing**: lock the aspect ratio, see ratios in size presets, and click the dimensions above the canvas to edit. The lock is saved with the project.

## 日本語

- **プリセットとプロジェクトを分離**：適用時はパターン設定だけを更新し、現在のプロジェクト・キャンバス・他のレイヤーを保持します。既存のプリセットも使用できます。
- **未保存の変更を確認**：新規作成・別のプロジェクトを開く・ウィンドウを閉じる際に、保存・保存しない・キャンセルを選べます。
- **画像をドラッグして追加**：PNG・JPG・WebP・SVGをドロップすると画像レイヤーを追加できます。右側に元のサイズと縦横比を表示します。
- **キャンバスサイズを簡単に調整**：縦横比の固定、サイズプリセットの比率表示に対応。キャンバス左上のサイズをクリックして編集でき、固定設定もプロジェクトに保存されます。
