# C-TextureMaker 1.5.0

## 繁體中文

Pixel 圖像轉換與圖層群組管理，公開預覽版。

- **新增 Pixel 圖樣**：調整像素密度、限制 2–256 色，使用自動取色、內建或自訂色板，並編輯個別顏色。支援平均／最近鄰取樣、抖色與色彩調整。
- **真正的像素尺寸輸出**：快速切換目前畫布尺寸與實際像素格尺寸，讓每個像素格以 1 px 匯出 SVG／PNG。
- **群組與圖層管理**：支援複選、Ctrl+G 群組、拖曳排序及移入／移出群組；可改名、收合與切換顯示，結構隨專案保存。
- **更直覺的圖片來源**：使用「全圖層／圖片／無圖片」切換；多個圖樣效果可共用下方圖片或群組，依圖層順序疊加，並以箭頭顯示套用關係。

舊專案可繼續開啟，原有圖片來源會保留；含 Pixel 或群組的專案請使用 1.5.0 或更新版本。升級時可將舊版的 data 資料夾複製到新版程式旁，延續自動存檔、偏好、預設與形狀庫。

## English

Pixel image conversion and grouped layer editing, public preview.

- **New Pixel pattern**: adjust pixel density and limit the palette to 2–256 colors. Use extracted, built-in or custom palettes, edit individual colors, and choose average/nearest sampling, dithering and color adjustments.
- **Native pixel-size export**: switch between the current canvas size and the actual pixel grid, exporting each cell as 1 px in SVG or PNG.
- **Groups and layer management**: multi-select, group with Ctrl+G, drag to reorder or move layers into and out of groups. Rename, collapse and hide groups; the hierarchy is saved with the project.
- **Clearer image sources**: switch between All layers, Image and No image. Multiple effects can share the image or group below and stack in layer order, with arrows showing the source relationship.

Older projects still open and retain their existing image bindings. Projects containing Pixel or groups require 1.5.0 or later. To keep autosaves, preferences, presets and shapes when upgrading, copy the old data folder beside the new application.

## 日本語

Pixel 画像変換とレイヤーのグループ管理を追加した公開プレビューです。

- **Pixel パターンを追加**：ピクセル密度と 2〜256 色の色数制限を調整できます。自動抽出・内蔵・カスタムパレット、個別の色編集、平均／最近傍サンプリング、ディザリング、色調整に対応します。
- **実ピクセルサイズで書き出し**：現在のキャンバスサイズと実際のピクセルグリッドを切り替え、1 セルを 1 px として SVG／PNG に書き出せます。
- **グループとレイヤー管理**：複数選択、Ctrl+G でのグループ化、ドラッグでの並べ替え、グループ内外への移動に対応。名前変更・折りたたみ・表示切り替えができ、階層もプロジェクトに保存されます。
- **分かりやすい画像ソース**：「全レイヤー／画像／画像なし」を切り替えます。複数の効果が下の画像やグループを共有し、レイヤー順に重なります。矢印で参照関係を確認できます。

旧プロジェクトと既存の画像参照は引き続き使用できます。Pixel やグループを含むプロジェクトには 1.5.0 以降が必要です。更新時は旧版の data フォルダーを新版の実行ファイルの隣へコピーすると、自動保存・設定・プリセット・形状ライブラリを引き継げます。
