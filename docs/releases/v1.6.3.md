# C-TextureMaker 1.6.3

[繁體中文](#繁體中文) · [English](#english) · [日本語](#日本語)

## 繁體中文

- **更新 Windows 圖示**：程式、工作列與檔案總管採用黃底黑線 Logo，與軟體品牌一致；提供多種尺寸，改善不同縮放比例下的顯示。
- 保留 [1.6.2 的形狀重繪與操作改善](https://github.com/ga643116/C-TextureMaker/releases/tag/v1.6.2#繁體中文)，專案格式與匯出方式不變。

升級前請關閉舊版，將原本的 data 資料夾複製到新版程式旁，即可保留自動存檔、偏好、預設與形狀庫。

## English

- **Updated Windows icon**: the application, taskbar and File Explorer now use the yellow-and-black logo, with multiple sizes for different display scales.
- Includes the [Shape redraw and editing improvements from 1.6.2](https://github.com/ga643116/C-TextureMaker/releases/tag/v1.6.2#english). Project and export formats are unchanged.

Before upgrading, close the old version and copy its data folder beside the new app to retain autosaves, preferences, presets and the shape library.

## 日本語

- **Windowsアイコンを更新**：アプリ、タスクバー、エクスプローラーで黄色地・黒線のロゴを使用します。複数のサイズで表示倍率に対応します。
- [1.6.2の形状再描画と操作改善](https://github.com/ga643116/C-TextureMaker/releases/tag/v1.6.2#日本語)を引き継ぎ、プロジェクトと書き出し形式は変更しません。

更新前に旧版を終了し、dataフォルダーを新版アプリの隣へコピーすると、自動保存・設定・プリセット・形状ライブラリを引き継げます。
